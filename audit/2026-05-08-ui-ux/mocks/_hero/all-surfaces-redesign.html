What's new on this surface
  • Spinner button mid-send — the send button shows a rotating icon while the message is in flight, with a ~100ms delay-before-show so fast sends don't flash. Today there's no feedback at all; you can double-tap and post twice.
  • One composer component instead of 5 inline copies of the same auto-resize textarea code.
  • Focus ring on the composer when active (try clicking into the textarea) — also applies to every button, link, and input across the app, not just the composer.
  • "(edited)" affix next to a message that's been changed — opens version history on tap.
  • Filter sub-bar (All / Mentions / Pins / Files) for quick scoping inside a space.

What's new on this surface
  • Status dots are the only color cue — cyan for in-progress, amber for in-review, red for blocked, green for done. Reduces visual chatter.
  • Agent chip with a small dot shows the assigned agent on each card — replaces the inconsistent assignee rendering today.
  • Floating + button for "Create a task" has an aria-label so screen readers announce it. Currently 7 icon-only buttons in tasks lack labels.
  • Section headers ("In progress · 2", "In review · 1") give counts at a glance — better than blank kanban columns on mobile where columns don't fit anyway.
  • Tap a card → opens the task in a sheet (one Sheet component, not three flag systems).

What's new on this surface
  • Day grouping (Today / Yesterday / explicit dates) — easier to scan than a single chronological stream.
  • Undo lives inline on each item — matches Suite's existing "security via undo, not consent" pattern. No separate menu.
  • Cards with subtle borders instead of an unbordered list — gives each action a tappable region with clear edges.
  • Empty state stays minimal per your call — when there's no activity, just the intro text, no chips or bot bubble.

What this is showing: the design system applied to populated versions of the three main surfaces. Same cyan brand, same typography scale, same spacing, same focus ring, same Button + Input + Sheet + EmptyState components reused everywhere. No invented values.

What's intentionally NOT changed: the data model, the backend, the URL structure, the keyboard shortcuts. The redesign is presentation-only.

# Empty state teaches

**Pattern.** An empty list explains what will appear there and offers the one action that fills it.

**Use when.** First run, or a filter that matches nothing.

**Avoid when.** The emptiness is an error; show the error and its fix instead.

**Evidence it worked.** New users reach a first item without asking where to start.

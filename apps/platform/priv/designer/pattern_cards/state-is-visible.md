# State is visible

**Pattern.** Every long-running or background job shows its current state and what happens next, where the person will look.

**Use when.** Uploads, agent jobs, syncs, deploys.

**Avoid when.** Sub-second actions, where a spinner is noise.

**Evidence it worked.** Fewer 'is it working' and 'did it go through' messages.

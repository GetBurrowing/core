# Inline validation

**Pattern.** Validate a field when the person leaves it, next to the field, in plain words that say how to fix it.

**Use when.** Forms with format rules (dates, ids, lengths).

**Avoid when.** A single free-text field where any input is valid.

**Evidence it worked.** Fewer failed submits and fewer repeated attempts on the same field.

# One decision per ask

**Pattern.** An agent asking a human for input asks for one decision, states the default it will take, and when.

**Use when.** Approvals, ambiguity, escalations.

**Avoid when.** Exploratory conversations where options are still forming.

**Evidence it worked.** Faster answers and fewer follow-up questions per ask.

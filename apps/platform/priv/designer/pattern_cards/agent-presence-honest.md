# Agent presence honest

**Pattern.** An agent's status says what it is doing now, and an agent that is not working never looks busy.

**Use when.** Agent avatars, typing indicators, task status chips.

**Avoid when.** Never; a false busy signal always costs trust.

**Evidence it worked.** Fewer 'is the agent stuck' questions.

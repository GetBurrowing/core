# Quiet by default

**Pattern.** Start new notification types quiet and let people opt up, rather than loud and making them opt down.

**Use when.** Any new event type with uncertain value.

**Avoid when.** Security and access events, which must reach the person.

**Evidence it worked.** Low mute rate on new types; opt-ups show real demand.

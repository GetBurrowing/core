# Show agent provenance

**Pattern.** Agent output shows where it came from (sources, tools used, who asked) in one tap.

**Use when.** Summaries, recommendations, any claim a person may act on.

**Avoid when.** Pure formatting or transcription, where provenance adds nothing.

**Evidence it worked.** Fewer 'where did this come from' questions; more output kept.

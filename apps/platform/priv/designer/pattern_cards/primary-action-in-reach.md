# Primary action in reach

**Pattern.** One primary action per view, visually dominant and inside the thumb or eye's resting zone.

**Use when.** A view exists to get one thing done (send, save, approve).

**Avoid when.** The view is a dashboard with several equal jobs; forcing one primary hides the others.

**Evidence it worked.** Fewer 'where is the button' messages; task completion without scrolling.

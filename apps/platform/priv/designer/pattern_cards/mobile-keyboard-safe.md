# Mobile keyboard safe

**Pattern.** On phones, inputs and their suggestion lists stay visible above the on-screen keyboard.

**Use when.** Any input that opens a list or a composer on mobile.

**Avoid when.** Desktop-only surfaces.

**Evidence it worked.** No 'can't see what I'm typing' reports from phone users.
